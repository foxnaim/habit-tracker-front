## About

Frontend application for the [Habit Tracker](https://github.com/foxnaim/habit-tracker) system. Built with Next.js and TypeScript for a fast, modern user experience.

## Features

- 📊 **Dashboard** — Overview of all habits and streaks
- ✅ **Check-in** — Mark habits as completed
- 📈 **Progress Charts** — Visual analytics
- 🎨 **Custom Themes** — Personalize your experience
- 📱 **Mobile Ready** — Responsive design

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Hooks | Custom React hooks |

## Getting Started

```bash
git clone https://github.com/foxnaim/habit-tracker-front.git
cd habit-tracker-front
yarn install
yarn dev
```
